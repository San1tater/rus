# 廢土求生 — v17.5

這是一款以瀏覽器為平台的單機戰鬥 / 探索生存遊戲。專案以廢土世界觀為主軸，融合探索、資源管理、角色裝備、Boss 戰鬥與基地建造等系統，並以純前端靜態方式實作，所有保存資料存放於瀏覽器的 localStorage。

## 專案概覽

- 以廢土生存為主題的單機遊戲
- 多區域探索與事件流程
- 裝備、背包、消耗品與改造系統
- Boss 戰與部位瞄準 / 護盾機制
- 基地建造、升級與資源加工流程
- 本地存檔 / 讀檔，無需後端服務

## 快速開始

### 方式 1：直接開啟

在專案根目錄中直接開啟 `index.html` 即可啟動遊戲。

> 注意：若使用 `file://` 直接打開，某些資源版本檢查可能會被跳過；建議使用簡單的本地靜態伺服器以避免跨域與資源載入問題。

### 方式 2：使用本地靜態伺服器（推薦）

Python：

```bash
cd rus
python -m http.server 8000
```

Node.js：

```bash
cd rus
npx http-server -c-1 . -p 8000
```

完成後在瀏覽器開啟：

```text
http://localhost:8000
```

## 遊戲玩法

- 探索多個地區，例如：廢棄工廠、實驗室、郊區公路、輻射沼澤與廢土核心
- 收集資源並升級角色裝備與背包
- 進行 Boss 戰，利用部位瞄準、射擊模式與技能進行攻擊
- 建造與升級基地設施，管理資源與生產流程
- 進度保存在瀏覽器的 localStorage 中，可讀取與備份

## 開發者說明

主要邏輯分散於 `js/` 資料夾中：

- `js/01-part.js`：定義所有資料、裝備、道具、資源版本與常數
- `js/02-part.js`：負責 UI 與探索畫面渲染
- `js/03-part.js`：實作存檔、讀檔、背包與核心遊戲流程
- `js/04-part.js`：Boss 場景與操作控制
- `js/05-part.js`：戰鬥計算、傷害與 Boss 特殊邏輯
- `js/06-part.js`：基地系統與初始化流程

## 開發建議

- 建議以本地 HTTP server 執行，避免直接 `file://` 造成的資源檢查問題
- 若要新增內容，優先在 `js/01-part.js` 中調整資料定義
- 若要修改 UI、Boss 或戰鬥流程，請檢視 `js/02-part.js`、`js/04-part.js`、`js/05-part.js`

## 常見問題

### Q: 為什麼有些圖示不更新？
A: 專案會檢測 asset version，並在必要時附加版本參數，避免快取問題；但直接以 `file://` 啟動可能會跳過版本探測。

### Q: 如何備份或還原遊戲進度？
A: 進度會存在瀏覽器 `localStorage` 中，使用瀏覽器開發者工具可查詢 `SAVE_KEY` 並手動備份/匯入。

### Q: 沒有 LICENSE 檔？
A: 目前倉庫中並未明確提供授權檔，若要公開分發或共同開發，建議新增 `LICENSE`。
