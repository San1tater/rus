# 廢土求生（RUS）

以繁體中文製作的純前端廢土生存遊戲，使用原生 HTML、CSS 與 JavaScript，無需安裝套件或啟動後端。遊戲入口為 `index.html`，目前頁面標示版本為 **v17.5**。

- **線上遊玩：**[https://san1tater.github.io/rus/](https://san1tater.github.io/rus/)
- **專案原始碼：**[San1tater/rus](https://github.com/San1tater/rus)

## 遊戲內容

遊戲介面以單頁形式提供四個主要區域：

- **探索：**在廢土區域與路線中前進，遭遇戰鬥或搜索物資；探索進度會保存。
- **戰鬥：**進行角色與敵人的戰鬥，也包含 Boss 戰與載具戰鬥。
- **後院：**管理土地、種植與收成、僕人、儲備、商人及相關生產與事件。
- **基地：**建造及升級設施、檢視生產統計、設定探索區域與行動偏好。

此外還有裝備、武器改造、載具與車組等系統。遊戲進度儲存在瀏覽器的 `localStorage`；重新開啟頁面時會載入存檔，並處理離線期間的結算。

## 開始遊玩

### 本機執行

1. 下載或複製此 repository。
2. 使用瀏覽器開啟根目錄的 `index.html`。

本專案沒有建置步驟或外部套件依賴。若瀏覽器直接開啟本機檔案時無法載入圖片等資源，可從專案目錄啟動靜態 HTTP 伺服器，再以瀏覽器開啟其網址。部署時需保留 HTML、CSS、JavaScript 與素材目錄之間的相對路徑。

## 專案結構

```text
rus/
├── index.html                 # 遊戲入口與模組載入順序
├── styles.css                 # 遊戲介面樣式
├── js/
│   ├── 00-utils.js             # 共用工具
│   ├── 01-constants.js         # 常數與設定
│   ├── 02–07-*.js              # 物品、敵人、區域、載具、Boss、後院資料
│   ├── 08-state.js             # 遊戲狀態與存檔
│   ├── 09-damage.js            # 傷害相關邏輯
│   ├── 10–13-render-*.js       # 角色、敵人、Boss 與載具繪製
│   ├── 14-ui-common.js         # 共用介面
│   ├── 15–18-*.js              # 探索、戰鬥、Boss 與載具戰鬥
│   ├── 19–20-*.js              # 車庫與車站
│   ├── 21–23-*.js              # 後院、商人與突襲
│   ├── 24-base.js              # 基地系統
│   ├── 25-boot.js              # 啟動、頁籤、主循環及離線結算
│   └── *_annotation.js         # 載具外觀與部位標註資料
├── icons/                      # 遊戲圖示與物品素材
├── images/                     # 背景及其他圖片素材
├── V9.5.html / V9.6.html       # 分層人偶編輯器的獨立版本
└── 其他 HTML 舊版與工具頁
```

`index.html` 會依序載入 `js/` 中的經典腳本，因此各模組共用全域狀態與資料。新增或調整模組時，請留意載入順序及其依賴；更新素材時，請維持程式碼使用的相對路徑。

## 開發與存檔

- 直接修改 HTML、CSS、JavaScript 或素材檔即可；不需要編譯。
- 遊戲進度由瀏覽器本機保存。清除網站資料或更換瀏覽器可能會移除存檔。
- `V9.5.html`、`V9.6.html`、`v1.html`、`v2.html`、`tankcss.html` 與 `拆分工具.html` 是根目錄中的獨立舊版或工具頁，不是目前主遊戲的入口。
