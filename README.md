# 廢土求生 (rus) — 瀏覽器單機遊戲 (v17.5)

簡介
----
廢土求生是一款以瀏覽器為平台的單機戰鬥與探索生存遊戲，強調資源管理、裝備成長、Boss 戰與基地建設。遊戲為純前端實作，進度儲存在瀏覽器 localStorage 中，無需後端服務。

主要特色
----
- 多區域探索：廢棄工廠、實驗室、郊區公路、輻射沼澤等場景
- 裝備與背包系統：武器、護甲、消耗品與改造
- Boss 戰系統：部位瞄準、護盾/弱點、技能與 AI 行為
- 基地系統：建造、升級與資源加工
- 本地存檔：使用 localStorage，方便備份與還原
- 完全在瀏覽器運行，無需安裝

快速開始
----
方式 1 — 直接開啟（簡單）
1. 在專案根目錄打開 `index.html`（雙擊或用瀏覽器開啟）。
2. 若遇到資源或快取問題，請改用本地靜態伺服器（推薦）。

方式 2 — 使用本地靜態伺服器（推薦）
- Python 3：
  ```bash
  cd rus
  python -m http.server 8000
  ```
- Node.js（http-server）：
  ```bash
  cd rus
  npx http-server -c-1 . -p 8000
  ```
然後在瀏覽器開啟：
```
http://localhost:8000
```

開發指引
----
- 建議使用本地 HTTP server 執行以避免 file:// 限制（例如資源版本檢查與跨域問題）。
- 若要新增或修改遊戲內容：
  - 資料定義（物品、武器、資源）請優先編輯 `js/01-part.js`。
  - UI 與畫面相關變更請編輯 `js/02-part.js`。
  - 戰鬥、Boss 行為與計算邏輯請檢視 `js/04-part.js`、`js/05-part.js`。
  - 存檔與流程管理在 `js/03-part.js`。
- 測試流程：開啟主頁後手動觸發遊戲流程、檢查 localStorage 中的 SAVE_KEY 與儲存格式。

儲存與備份
----
遊戲進度儲存在瀏覽器 `localStorage`，可以用開發者工具查詢並匯出對應的 key（搜尋 `SAVE_KEY` 或檔案內相關字串）。手動備份：複製 localStorage 的 JSON 字串並保存為檔案；還原時將字串貼回對應 key 並重新載入遊戲。

常見問題 (FAQ)
----
Q: 為何某些圖示或資源沒有更新？  
A: 專案會在載入資源時帶入版本參數以避免快取，但若直接使用 `file://` 開啟，部分檢測流程可能被跳過，建議使用本地伺服器。

Q: 我想新增資源檔（icons / images）後自動快取失效，該怎麼做？  
A: 更新版號或在資源路徑上加入查詢參數（例如 ?v=...）可強制瀏覽器重新載入。
