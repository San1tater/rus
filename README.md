# 廢土求生（RUS）

以繁體中文製作的純前端廢土生存遊戲，使用原生 HTML、CSS 與 JavaScript，無需安裝套件或啟動後端。遊戲入口為 `index.html`，目前頁面標示版本為 **v17.5**。

- **線上遊玩：**[https://san1tater.github.io/rus/](https://san1tater.github.io/rus/)
- **專案原始碼：**[San1tater/rus](https://github.com/San1tater/rus)

## 遊戲內容

遊戲介面以單頁形式提供四個主要區域：

- **探索：**在廢土區域與路線中前進，遭遇戰鬥或搜索物資；探索進度會保存。
- **戰鬥：**進行角色與敵人的戰鬥，也包含 Boss 戰與載具戰鬥。
- **後院：**管理土地、種植與收成、僕人、儲備、商人及相關生產與事件。
- **基地：**建造及升級設施、檢視生產統計、設定探索區域與行動偏好。

此外還有裝備、武器改造、載具與車組等系統。遊戲進度儲存在瀏覽器的 `localStorage`；重新開啟頁面時會載入存檔，並處理離線期間的結算。

## 開始遊玩

### 本機執行

1. 下載或複製此 repository。
2. 使用瀏覽器開啟根目錄的 `index.html`。

本專案沒有建置步驟或外部套件依賴。若瀏覽器直接開啟本機檔案時無法載入圖片等資源，可從專案目錄啟動靜態 HTTP 伺服器，再以瀏覽器開啟其網址。

## 探索交戰邏輯與強度榜

以下是依目前程式的交戰流程、資料表與傷害結算整理的**遊戲內實戰評估**，不是只按武器名稱、口徑或單發數字排序。探索敵人、玩家裝備與載具乘員配置會改變結果；名次是同一系統、同等稀有度／彈藥品質及正常彈藥供應下的整體判斷，不代表每場固定勝負。主要實作見 [`js/00-utils.js`](js/00-utils.js)、[`js/15-explore.js`](js/15-explore.js)、[`js/16-combat.js`](js/16-combat.js)、[`js/18-vehicle-combat.js`](js/18-vehicle-combat.js)、[`js/02-data-items.js`](js/02-data-items.js) 與 [`js/05-data-vehicles.js`](js/05-data-vehicles.js)。

### 先釐清交戰判定

- **「可被發現半徑」不是主動探測距離，也不是攻擊者的索敵距離。**共同開火條件是 `距離 ≤ 目標的可被發現半徑`，而且 `距離 ≤ 攻擊者自身射程`。敵人的可被發現半徑隨稀有度提高而縮小；載具則按車高計算。
- **探索觸發與戰鬥中的開火是兩道不同判定。**探索事件會按玩家行動模式、敵人可被發現半徑與位置決定交戰／先手；進入戰鬥後，各攻擊者仍要按各自射程與目標半徑判斷能否交戰。載具戰也會持續把前方新發現的事件敵人加入交戰，因此不能只把戰鬥開始時畫面中的敵人當成整場敵群。
- **隱蔽的價值在於降低被發現、改變先手機會或避開交戰，不是直接增加命中／傷害。**程式的探索觸發有特殊的潛行先手避戰分支；一旦真的交戰，傷害、射程與命中仍按戰鬥規則處理。載具體型也會影響其被發現半徑。
- **命中不由槍枝資料中的 `range` 小數直接決定。**探索步戰使用武器類型熟練度、當下射擊連發階段、瞄具加成及先手懲罰計算命中；命中率最高封頂 75%。連續射擊由點射逐步轉成短點射、長點射、掃射，模式倍率依序下降（1.6、1.25、1.0、0.65）。因此射速高的槍有更高出手機會，但連續掃射命中率會下降。
- **射程先決定能不能打，命中才決定是否命中。**步戰常見基礎射程：手槍 8m、衝鋒槍 15m、突擊步槍 30m、機槍 50m、狙擊槍 80m、霰彈槍 15m；標記短射程的步槍為 20m，手榴彈 30m，近戰實際交戰距離約 0.75m。玩家會優先攻擊可交戰敵人中最近者；敵人有可用 RPG 時會先嘗試 RPG，之後才用一般槍械。
- **一般槍械的傷害主要來自實際消耗的彈藥，而不是槍枝面板傷害。**彈藥稀有度倍率會放大彈藥傷害；穿深與被命中的部位護甲共同決定生命傷害或只削護甲。暴擊率看武器稀有度，暴擊倍率看彈藥稀有度；高傷但穿深不足的彈藥打在有甲部位可能只磨護甲。
- **速度同時影響探索節奏與射擊時的相對位置。**步行速度會受超重懲罰；載具支援／行進階段按車速移動，較快通過路段會改變敵人接近、發現及彈丸抵達時間。子彈飛行時間依距離與彈速計算；這不等同於額外命中加成。
- **載具不是把步戰的玩家角色換成一條 HP。**載具武器由車組自動選目標、同步瞄準及按各自射擊節奏開火；炮手等級、炮手專精影響命中，敵人先手時會受命中懲罰。載具遭擊中時另抽車體／炮塔部位，再抽內部乘員、引擎、履帶、炮塔、武器或彈藥架；穿深不夠會跳彈，ERA 對 HEAT 有特別高的防護加成。引擎、履帶、駕駛員、炮塔、武器損毀與彈藥架殉爆都可能比單純 HP 更早令載具失去作戰能力。

### 步戰武器強度榜

按探索步戰的綜合實戰價值分級；同級內的差距取決於彈藥、熟練度、先手及敵人護甲。這是**武器類型／配置榜**，不是宣稱同類每一把槍完全等價。

| 等級 | 武器／配置 | 強項與限制 |
| --- | --- | --- |
| S | **狙擊槍：SVD、SV-98** | 80m 射程讓玩家較早進入可射擊距離；7.62×54 的高階彈兼有高傷與約 32mm 穿深。SVD 射速較快；SV-98 單發間隔長。長射程不會穿透目標自己的可被發現半徑限制，也不保證命中。 |
| S | **高階彈 9×39 突擊步槍／VSS：AS VAL、SR-3M、VSS** | SP-6 傳奇彈有 60 基礎傷害、22 穿深，稀有度再放大傷害；AS VAL／SR-3M 可達 900 RPM，VSS 具狙擊槍射程。缺點是 9×39 武器的實戰射程短（VSS 例外為 80m），彈匣較小或彈藥負重較高。 |
| A | **機槍：PKP、PKM、RPD、RPK-16** | 射程 50m、較大的彈匣／彈鏈帶來穩定持續火力；7.62×54 BS 兼具高傷與穿深。相對狙擊槍較短射程，連續火力進入掃射階段後命中率會降低，重量也拖慢探索速度。 |
| A | **突擊步槍：AK-12、AK-74 系、AK-103／AKM 系** | 30m 射程與可觀射速、彈匣容量兼顧泛用性；高階 5.45／7.62 彈可提升穿甲。AK-12 射速較快；選彈比單看槍型重要。短射程型（如 AKS-74U、AK-105）降至 20m，較不利於提早接敵。 |
| B | **霰彈槍／手槍** | 霰彈槍在 15m 內可用多彈丸彈藥造成近距爆發，但逐發命中與穿甲效率受彈種影響；手槍射程僅 8m，多數情況是副武器或主武器彈藥耗盡後的備援。高傷低穿深彈對護甲目標不一定有效。 |
| B（情境型） | **手榴彈：RGO、RGN、F-1、VOG 等** | 玩家每次攻擊有機率優先投擲；投擲命中率按投擲熟練度等計算。破片逐片判定命中、暴擊與穿甲，可波及多名敵人（最多四個目標），對密集敵群有價值；但不應把破片總數當成全部打在單一敵人身上，且存量有限。 |
| C | **近戰：Kukri、刺刀** | 不耗彈，且攻擊週期可能有多次命中；但有效距離不到 1m，命中率依近戰熟練度，基礎穿深低，接近敵人之前會承受風險。 |

**配置建議：**優先提升彈藥品質與對應熟練度，再看射速／彈匣／瞄具。遠距先手選狙擊槍；兼顧火力與移動選突擊步槍；高熟練、能承擔重量且備彈充足時選機槍。瞄具增加命中率，但不延長射程、不改變隱蔽，也不取代穿深。

### 載具與車載武器強度榜

載具排名假設完整車組、炮手等級相近、武器與彈藥健康且彈藥供應正常。先看整車；再看武器，因為穿深、射速、命中、射程、目標偏好、彈種自動選擇與濺射會互相牽制。

| 等級 | 載具 | 綜合評價 |
| --- | --- | --- |
| S | **T-80U／T-80UK／T-80UM** | 三者資料中的裝甲與 ERA 相同：車體正面 600、炮塔正面 700，ERA 對 HEAT 加 400、對動能加 120；125mm 2A46M-1 射程 400m，彈種包含高穿深 3BM42、HE 3OF26 與 HEAT 3BK29，另有 NSVT／PKT。綜合火力與生存力最強。T-80UK／UM 的支援時間較長；程式沒有給它們額外的命中或裝甲優勢。 |
| A | **T-80BV、T-80B、T-80** | 同為 125mm 2A46 與機槍組合，射程與高階彈威力仍強。BV 有 ERA，但其資料防護加成低於 T-80U 系；T-80B 比基礎 T-80 更耐打。裝甲厚重不代表免疫，敵方穿深超過命中部位裝甲後仍會造成內部損傷。 |
| A | **BMP-3** | 100mm 2A70 高爆彈與 30mm 2A72 並用；2A70 高爆對單體與群體都強，車載 HE 直接命中會走特殊高爆生命傷害規則，且具大範圍濺射，另有 30mm 補充火力。缺點是沒有 T-80U 系的重裝甲／ERA，較易受穿透後的內部損傷。 |
| B+ | **BMD-4** | 同樣有 100mm 2A70＋30mm 2A72，火力上限接近 BMP-3；但裝甲較薄、載員容量較低，整體耐久與支援續航不及 BMP-3。 |
| B | **BMP-2、BTR-90** | BMP-2 有 30mm 2A42、機槍與 ATGM；BTR-90 也有 30mm、機槍與 ATGM，機動與武器多樣性不差，但穿透後生存力遠遜 T-80。ATGM 射程最遠（500m），然而慢速飛行、射擊間隔長，且其目標選擇偏向射程內較遠的敵人，不適合當成每次都能快速清場的主武器。 |
| C | **BMP-1／BMP-1M** | BMP-1 的 73mm HE／HEAT 能打出濺射，並有 ATGM；BMP-1M 改為 30mm 2A72。火力各有情境優勢，但裝甲與射擊節奏不及較高階車輛。 |
| C | **BTR-82A／BTR-80A** | 30mm 2A72 射速高、穿深和對群體的高爆彈種可用，車速也快；但車體裝甲仍薄，不能把高射速誤當成對重裝甲的可靠穿透。82A 的裝甲與支援時間略優於 80A。 |
| C− | **BTR-82／BTR-80** | 14.5mm KPVT＋PKT，車速高、載員容量大，對探索步兵足以造成有效火力；但缺少 30mm 主炮／ATGM，且裝甲防護最低。BTR-82 比 BTR-80 快、略耐打且支援時間更長。 |

**車載武器實戰順位（探索敵群）：**

1. **125mm 2A46／2A46M-1（T-80 系）**：對單體時彈種挑選偏向 AP／HEAT；兩名以上可用敵人時會優先選 HE，搭配 3OF26 的長距離濺射，群戰收益遠高於只看單發穿深。射擊週期較慢，命中率受車型基礎值、炮手與先手影響。
2. **100mm 2A70（BMP-3／BMD-4）**：只配 3UOF17 HE，基礎傷害高且 HE 濺射半徑最大級；依密集敵人選目標，對步兵群尤其有效。缺乏 AP 彈，對有護甲目標的效果受特殊 HE 規則與目標類型影響。
3. **30mm 2A42／2A72**：射速與持續火力較佳；穿甲預設適合直擊，改用 HE 時傷害穿深較低但增加濺射。2A42 的射擊節奏較快，2A72 在不同車型的射擊設定可能不同；兩者都不應只按單發傷害比較。
4. **73mm 2A28（BMP-1）**：可在 HE 與 HEAT 間切換，具濺射且目標選擇偏密集群；彈量有限、單發節奏慢，整車的其他能力也較落後。
5. **ATGM**：500m 射程與高穿深，但彈速慢、射擊週期長、彈量少，且程式在有其他目標選擇時偏向遠端目標；是遠距／高裝甲情境的補充，不是通用 DPS 第一名。
6. **KPVT／NSVT／PKT**：彈鏈持續性好、可快速射擊，但射程 200m、穿深低於主炮。穿燃與高爆彈鏈的傷害／穿深特性不同；對重甲的順位明顯低於主炮與 30mm 穿甲彈。

### 載具榜的關鍵交互作用與例外

- 載具車速依車型資料取值（支援時用道路速度），主要影響探索前進／敵人相對位置；**目前載具命中率公式沒有直接把車速當作命中懲罰或加成**。駕駛本能天賦增加車速 10%，並降低履帶損傷。
- 車載武器的射程上限不是唯一限制，還要滿足目標可被發現半徑。炮手命中率有車型基礎值、等級與專精影響，最後封頂 75%；敵方先手時另有懲罰。
- 車載彈藥基礎傷害會先乘以 **5**；車載暴擊使用傳奇等級公式（60% 暴擊率、7.5 倍暴擊倍率）。這使車載單發與步戰單發不能直接用面板數字比較。
- **高爆的特殊規則很重要。**車載主炮 HE 直擊傷害會忽略一般穿甲檢查並直接造成生命傷害；濺射另按彈種半徑衰減。其他車載彈種濺射則同時衰減傷害與爆炸穿深；未命中時有濺射彈種仍可能造成較弱的範圍傷害。
- 2A46 系在目標較多時優先挑 HE，並偏好對密集群挑選目標；ATGM 偏好射程內較遠目標；同步組可讓不同武器集中同一目標。這些瞄準偏好會改變實際擊殺效率。
- T-80U／UK／UM 的高裝甲仍有弱點：不同部位有不同命中權重，HEAT 會遇到額外 ERA 防護；穿透後又會抽取彈藥架、乘員、引擎、履帶、武器或炮塔等內部結果。彈藥架累積損傷可引發殉爆，履帶或引擎損壞也可能迫使下車。
- 因此，**對大量普通步兵清場時，BMP-3 的 HE 濺射可能比純防護排名更實用；面對高穿深威脅或追求整體存活率時，T-80U 系仍是首選。**若缺彈、炮手／車組受傷、武器損壞或炮塔卡死，任何紙面排名都會失效。

## 開發與存檔

- 直接修改 HTML、CSS、JavaScript 或素材檔即可；不需要編譯。
- 遊戲進度由瀏覽器本機保存。清除網站資料或更換瀏覽器可能會移除存檔。
- `V9.5.html`、`V9.6.html`、`v1.html`、`v2.html`、`tankcss.html` 與 `拆分工具.html` 是根目錄中的獨立舊版或工具頁，不是目前主遊戲的入口。
