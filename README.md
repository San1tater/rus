# 廢土求生 (rus)

> 瀏覽器單機求生遊戲 — 版本 v17.5

一款以純前端（HTML/CSS/JavaScript）實作的廢土題材單機遊戲，玩家可在瀏覽器中探索廢墟、收集資源、強化裝備、挑戰 Boss，並建立與維護基地。遊戲不依賴後端伺服器，所有進度透過瀏覽器 localStorage 保存。

版本與語言組成

- 目前版本：v17.5
- 主要技術：JavaScript、HTML、CSS
- 倉庫語言分佈（大約）：JavaScript 61%、HTML 26%、CSS 13%

主要特色

- 探索與戰鬥：進入多個區域偵查資源、擊倒敵人並搜刮素材
- 裝備系統：武器、護甲、彈藥、消耗品、模組與稀有度機制
- Boss 戰：分部位攻擊、護盾與弱點系統、Boss 技能與 AI 行為
- 基地建設：建造與升級設施、資源加工、農業與後勤管理
- 存檔機制：遊戲進度保存在 localStorage，支援手動備份與還原
- 純前端：無需安裝或構建工具，直接用瀏覽器即可遊玩

檔案與目錄結構概覽

- `index.html`：遊戲入口與主 UI 容器
- `styles.css`：全域樣式與介面設計
- `js/01-part.js`：資料定義（物品、武器、裝備、區域、版本設定）
- `js/02-part.js`：UI 渲染與探索畫面邏輯
- `js/03-part.js`：存檔、背包、道具、探索流程與主要遊戲狀態
- `js/04-part.js`：Boss 場景與操作流程
- `js/05-part.js`：戰鬥計算、傷害與 Boss 特殊邏輯
- `js/06-part.js`：基地系統與主循環
- `icons/`、`images/`：圖示與靜態資源
- `v1.html`、`v2.html`、`V9.5.html`：歷史版本或備份頁面
- `拆分工具.html`：開發用的內容拆分/工具頁面

快速開始

方式一：直接開啟（快速）

1. 下載或 clone 本倉庫
2. 直接在檔案管理器雙擊 `index.html` 或以瀏覽器開啟該檔案

注意：直接使用 file:// 開啟在某些瀏覽器或情境下會造成資源或版本檢查機制異常，若遇到問題請改用本地伺服器執行。

方式二：使用本地靜態伺服器（建議）

- Python 3：

```bash
cd rus
python -m http.server 8000
```

- Node.js（http-server）：

```bash
cd rus
npx http-server -c-1 . -p 8000
```

然後開啟瀏覽器：

http://localhost:8000

遊戲注意事項與除錯

- 快取機制：專案會使用 ASSET_VERSION（或查詢參數）來避免舊快取。若更新圖片或素材後看不到變化，請強制重新整理或重啟本地伺服器。
- 存檔備份：遊戲進度儲存在 localStorage；可透過瀏覽器開發者工具匯出或手動備份 localStorage JSON。
- 無多人功能：本專案為單機遊戲，沒有後端同步或多人功能。

開發與修改指南

- 新增/修改資料（物品、武器、區域、掉落等）：編輯 `js/01-part.js`
- UI 或探索畫面調整：編輯 `js/02-part.js`
- 存檔、背包、流程控制：編輯 `js/03-part.js`
- Boss 與戰鬥邏輯：編輯 `js/04-part.js`、`js/05-part.js`
- 基地系統與主循環：編輯 `js/06-part.js`

常見問題

Q：直接開啟 `index.html` 會不會造成問題？
A：通常可行，但為避免快取或資源版本檢查問題，建議使用本地 HTTP server。

Q：為何更新素材後看不到變化？
A：請確認瀏覽器有做強制重新整理（Ctrl/Cmd+Shift+R）或停止/重啟本地伺服器；專案也會用 `ASSET_VERSION` 來避免舊快取。
