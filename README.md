# 廢土求生 (rus)

> 瀏覽器單機求生遊戲，版本 v17.5

這個專案是一款純前端的廢土求生遊戲，玩家可在瀏覽器中探索廢墟、收集資源、強化武器與裝備、挑戰 Boss，並建立與維護基地。遊戲沒有後端伺服器，進度直接保存在瀏覽器的 localStorage 中，方便本地遊玩與備份。

## 遊戲內容概覽

- 探索與戰鬥：進入多個異常區域，偵查物資、擊倒敵人、搜刮素材
- 裝備系統：武器、護甲、彈藥、消耗品、模組與稀有度提升
- Boss 戰：部位攻擊、護盾、弱點、技能與 AI 行為
- 基地建設：建造、升級、資源加工、農業、僕人與後勤管理
- 存檔機制：使用瀏覽器 localStorage 保存進度
- 運行方式：純 HTML/CSS/JavaScript，無需安裝、無需構建工具

## 專案結構

- `index.html`：遊戲入口與主 UI 容器
- `styles.css`：全域樣式與介面設計
- `js/01-part.js`：資料定義、物品、武器、裝備、區域、版本設定
- `js/02-part.js`：UI 渲染與探索畫面邏輯
- `js/03-part.js`：存檔、背包、道具、探索流程與主要遊戲狀態
- `js/04-part.js`：Boss 場景與操作流程
- `js/05-part.js`：戰鬥計算、傷害與 Boss 特殊邏輯
- `js/06-part.js`：基地系統與主循環
- `icons/`：遊戲圖示、物品與建築圖示
- `images/`：靜態圖片資源
- `v1.html`、`v2.html`、`V9.5.html`：歷史版本或備份頁面
- `拆分工具.html`：內容拆分/工具頁面
- `README.md`：專案說明文件

## 快速開始

### 方式一：直接開啟

直接雙擊或用瀏覽器開啟專案根目錄中的 `index.html` 即可開始遊玩。

### 方式二：使用本地靜態伺服器（推薦）

這種方式較穩定，尤其適合資源快取和版本檢查。

Python 3：

```bash
cd rus
python -m http.server 8000
```

Node.js：

```bash
cd rus
npx http-server -c-1 . -p 8000
```

然後在瀏覽器中開啟：

```text
http://localhost:8000
```

注意：如果直接使用 `file://` 開啟，部分資源版本檢查或快取機制可能不正常，建議使用本地伺服器執行。

## 遊戲系統重點

### 區域與戰鬥

專案內包含多個地圖區域，例如：

- 廢棄工廠
- 廢棄實驗室
- 郊區公路
- 輻射沼澤
- 廢土核心

每個區域都設計有不同的敵人、資源分布與掉落組合，讓玩家在探索時有不同的風險與回報。

### 裝備與進度

角色可以收集與升級：

- 武器
- 盔甲與護具
- 彈藥
- 醫療與消耗品
- 材料與基建資源

稀有度與傷害/防禦屬性直接影響戰鬥結果，玩家需要在資源管理與戰鬥效率之間取得平衡。

### 基地與生產

遊戲還包含基地系統，玩家可透過資源加工、建造與升級來提升戰力，同時也有農業、種植與後勤配給相關設計。

## 開發與修改建議

- 若要新增或修改資料（武器、裝備、道具、區域定義），請優先檢視 `js/01-part.js`。
- 如果要調整 UI 或探索畫面，請檢查 `js/02-part.js`。
- 若要改動進度保存、背包、道具與流程控制，請檢查 `js/03-part.js`。
- 戰鬥、Boss 行為與計算邏輯位於 `js/04-part.js` 和 `js/05-part.js`。
- 基地系統與主循環則主要在 `js/06-part.js`。

## 儲存與備份

遊戲進度保存在瀏覽器 `localStorage`，其內容可透過開發者工具查看；如需手動備份，請匯出相關儲存資料或整個 localStorage JSON。

## 常見問題

### Q：直接開啟 `index.html` 會不會有問題？
A：可以開啟，但為了避免快取與資源版本檢查問題，建議使用本地 HTTP server。

### Q：更新圖片或素材後為何沒有立即看到變化？
A：專案會透過 `ASSET_VERSION` 或查詢參數避免舊快取，若本地瀏覽器仍保留快取，請重整頁面或重新啟動伺服器。

### Q：這是單機遊戲嗎？
A：目前這個專案是單機前端遊戲，沒有後端同步或多人連線功能。
