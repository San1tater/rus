2 · 无缝处理参数

◆ 无缝模式（核心）
边缘垂直翻转（用户方案）
右边缘条带的内容 = 左边缘条带的 上下颠倒 版本。
当图片以「正常 → 垂直翻转 → 正常 → 垂直翻转」交替平铺时，左右接缝严格连续。
★ 若游戏引擎用交替垂直翻转平铺方式，选这个。
边缘条带宽度：参与翻转的边缘区域宽度，越宽越明显但越自然（推荐图宽的 10%~25%）。
过渡混合：0% = 右边缘直接替换为翻转版；100% = 从原右边缘渐变到翻转版；推荐 30~70%。
勾选后，右边缘 x=W-1 的像素列会与左边缘 x=0 的像素列严格相同（垂直翻转关系）， 保证任何平铺方式的接缝无跳变。
◆ 输出尺寸
「保持原尺寸」不会改变任何像素。

接缝验证（两种平铺方式，请对照你游戏里的滚动方式看）
▸ 方式 A：简单横向平铺（正常 → 正常 → 正常）
常规“复制+并排”滚动。如果游戏只做这种平铺，接缝处仍会跳变——除非用 180° 旋转模式。
▸ 方式 B：交替垂直翻转平铺（正常 → 垂直翻转 → 正常 → 垂直翻转）★
如果游戏引擎使用这种交替翻转方式滚动，那么用「边缘垂直翻转」模式即完全无缝。
